เนื้อหาผ่านการตรวจแหล่งข้อมูลที่ใช้ในบทความ ได้แก่ Hong Kong Observatory, Myers Briggs Foundation, The Myers Briggs Company, กรมศิลปากร, ศูนย์มานุษยวิทยาสิรินธร และไทยรัฐ เนื้อหาทุกหน้าระบุข้อจำกัดของศาสตร์หรือความเชื่อ และใช้ชื่อผู้เขียนที่มีอยู่จริงคือ สายมู โดยไม่ระบุคุณวุฒิที่ไม่ได้ยืนยัน

กลุ่มผู้อ่านคือคนไทยที่อยากเริ่มทำความเข้าใจแต่ละหัวข้อ เจตนาค้นหาเป็นการหาความรู้ คำหลักคือ ปาจื้อคืออะไร, โหราศาสตร์ไทยคืออะไร, MBTI คืออะไร และมูเตลูคืออะไร ส่วนคำรองครอบคลุมสี่เสาชะตา ธาตุทั้งห้า ดาวประจำวัน ลัคนา ตัวอักษร MBTI และที่มาของสายมู ไม่ได้มีข้อมูลปริมาณค้นหาหรือคำรับรองอันดับจากเครื่องมือ keyword

## ตรวจงานรวม

* `bun test`: 34 ผ่าน รวมเวลารอ POST แบบกำหนดเอง การอ่าน response body และการรักษาข้อมูล error 429
* `bun run build`: ผ่าน บทความทั้ง 4 หน้าเป็น static HTML
* Browser QA ด้วย Chromium: หน้าแรก คลังความรู้ และบทความทั้ง 4 หน้า HTTP 200, H1 และ canonical อย่างละหนึ่ง, ลิงก์จากการ์ดครบ, ไม่มีเนื้อหาล้นจอเดสก์ท็อปหรือมือถือ
* ดวงคู่บนมือถือ 390 × 844: เลื่อนจากปุ่มด้านล่างกลับ scrollY 0, มองเห็น loading และรับผลจำลองหลัง 46 วินาทีจาก POST ครั้งเดียว ไม่พบ browser runtime error
* Hero แสดงภาพนิ่งแทนคลิปเมื่อเปิด reduced motion ตรวจภาพบนเดสก์ท็อปและมือถือแล้ว ตัวตรวจ UI แจ้งเฉพาะ gradient text เดิมใน headline ซึ่งอยู่นอกขอบเขตแก้ animation

ยังไม่ได้ทดสอบคำทำนายจริงผ่าน production หรือประเมินน้ำเสียงจากการเรียกโมเดลใหม่ บทความไม่รับประกันอันดับค้นหา ไม่มีการเปลี่ยนข้อมูลดวงที่บันทึกไว้

ตรวจ simplification แล้วไม่พบการลดความซับซ้อนเพิ่มเติมที่จำเป็น โครงสร้างหน้าใช้ข้อมูลบทความร่วมกันโดยไม่เพิ่ม CMS หรือ dependency
